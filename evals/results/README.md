## 评估方法与边界

- 每案使用新建且不继承历史的回答 Agent 上下文。每个输入目录只复制该案例、顶层说明及固定版本的完整 skill；复制品与被评估 skill 逐文件哈希一致，未包含 rubric、历史答案或历史评分。
- 回答者只分析模拟证据，没有运行案例中的业务命令。完成后交给新的独立评分者，逐项检查 `must` 与 `must_not` 并引用回答证据。
- 输入与上下文分开，但执行环境没有操作系统级文件访问隔离；访问范围由任务指令限定。因此这不是对恶意越界访问的隔离证明。
- 使用当前 Codex 会话默认模型配置，运行记录未暴露精确模型标识；不推测模型版本。结果是单次定性评估，不是稳定通过率或跨模型基准。
- 模拟评估不能证明目标项目的 Tests、Guardrails、ARBITER 实际运行、CI 受到保护或消费者接入正确。本仓库的 Python 测试及包校验是另外的实际执行检查。
