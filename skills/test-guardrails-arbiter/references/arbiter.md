# ARBITER：让路径的不变量在动手前出现

在某类路径需要额外上下文、明确写入归属或保护不可逆行为时读本文件。ARBITER 在原文中是机器可读的路径不变量清单，不是 LLM 裁判、reviewer 名单，也没有在原文中定义英文缩写展开。

## 路径命中后先读取什么

识别计划修改的路径和相关 owner，读取全部命中的清单及其要求的资料，同时保留比较基线中的清单版本。重命名或移动要包含旧路径与新路径，删除要包含旧路径；修改涉及新路径时追加匹配，不能只读取任务开始时的第一份清单。多个清单相互冲突时定位策略定义和实际架构，不擅自挑选较宽松的一条。

| 字段 | 作用 |
| --- | --- |
| `id` | 稳定地标识规则，便于定位、汇报与追踪 |
| `risk` | 表达风险等级，引导关注不可逆结果和验证缺口 |
| `paths` | 声明哪些仓库相对路径触发这份清单 |
| `invariant` | 用自然语言说明必须保持的性质与理由 |
| `read` | 动手前需要的仓库文件或其他明确上下文 |
| `forbid` | 执行器能够检查的禁止模式，需配套明确匹配语义 |
| `checks` | 修改完成后应执行的已有检查标识或入口 |

[清单示例](../assets/arbiter.example.toml) 用于按项目改写。先确认路径、上下文文件与检查入口确实存在，核对当前执行器支持的 schema；仅创建 TOML 并不会自动启用检查。

## 区分自然语言约束与确定性检查

`invariant` 帮助 Agent 和人理解约束；`forbid` 只能拦截其模式覆盖到的新增内容。原文 ARBITER 对 diff 的新增整行匹配，不能假设它自动区分注释、解析 SQL 或理解所有等价写法。大小写、通配符、词边界和路径 glob 行为都必须由真实执行器及其契约测试确认。

路径命中时，即使没有新增行、只是删除、重命名或移动文件，也应读取不变量并执行适用检查。新增行扫描无法单独证明删除保护逻辑、改变执行顺序或间接调用仍然安全。将这些缺口交给相应行为测试、结构检查和必要的语义审查，不能将“未命中 forbid”写成“所有不变量已获证明”。

模型可以解释上下文、提出风险线索和修复建议；这些属于语义审查意见。除非有可复验工具证据，不得冒称机器判定，也不得覆盖测试或规则执行器的结论。需要人对业务取舍或不可逆动作作判断时，沿用项目及用户已经确定的职责与授权。

## 先校准边界，再执行禁止

从真实合法与违规改动构造样例，明确哪些行为不能发生、哪些有风险但属于既定业务机制。不要把一种项目中的决策扩展为全语言禁令。

原文迁移案例刻意允许合法表退役、部分孤儿数据清理和既定 TTL 保留机制，同时阻止特定不可逆清空或分区删除操作。这反映的是其数据生命周期约定；不代表其他项目也应允许 `DROP TABLE`，或全局禁止外键。移植时应从本项目不变量和实际数据库语义重新确定模式。

为注释、文档、测试夹具和生成文本设置符合目的的精确 scope 或例外，并验证不会吞掉真实违规。策略文件还必须能被版本控制发现；检查忽略规则，防止清单存在本地却没有进入候选提交。

## 动手后用同一范围收口

以固定比较基线识别最终变更。PR 使用确定的 revision；本地按项目分支约定计算并记录 merge-base，同时覆盖暂存、未暂存及将被提交的新增文件。不要依赖会随远端更新移动的名称而不记录实际 SHA。

对 base 清单匹配旧路径、candidate 清单匹配新路径，并比较两版清单对全部变更路径的命中差异。删除、重命名和移出保护目录不会自动取消原不变量；以适用不变量及 checks 的并集作为核验起点，解释迁移或替代关系。新增规则也要进入核验，不得只按候选清单重算后宣称“没有命中”。

检查清单本身的删除、`paths` / `read` / `forbid` / `checks` 变更，以及关联检查的 scope、模式和入口差异。对合法的规则变更说明依据及替代证据；不能通过删检查、缩小路径或改写禁止模式绕过原约束。执行器或原入口不可用时，明确记录缺失，不能伪称执行成功；参见 [Guardrails 的策略核验](guardrails.md#规则自身也要有证据)。

执行新增行扫描及适用的真实 checks，将结果绑定到本次实际观察的源码快照及策略版本。返回命中规则、风险、不变量、具体证据及修复 owner。违规应改变候选设计或实现；必要策略读不出或比较基线缺失时，先恢复检查能力。

高风险路径优先确认状态的唯一 writer、旁路和外部副作用。通过检查本身不会授权新的发布、数据操作或其他外部动作；仍按当前用户请求的范围执行。临时例外沿用 [Guardrails 的例外处理](guardrails.md#存量债务与例外不混用)，不能通过重试、改拼写或扩充 baseline 绕过不变量。
