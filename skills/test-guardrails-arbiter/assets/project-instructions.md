# 项目常驻指令片段

仅在任务要求建立或改进项目接入时使用。先阅读现有 `AGENTS.md` / `CLAUDE.md` 及实际规则，替换全部 `<占位项>`，按宿主和目录作用范围合入少数必要条目；不要覆盖整个文件、重复维护两份规则或把本模板直接当成生效配置。

```markdown
## 变更验证

- 修改前，将预期路径与 `<实际路径清单位置>` 匹配，读取命中规则要求的背景。修改后用真实差异重新匹配，包含新增、删除和改名。
- 按 `<真实检查入口及参数>` 运行命中规则要求的检查。将原始需求的验收条件关联到实际执行证据；检查开始和结束时核验代码、脏文件内容及策略版本一致。
- 对比基点和候选中的清单、路径范围、必需 checks、规则模式与 CI 任务，记录约束变化；不能只按被删减的候选规则宣告通过。
- 保留执行者日志、原始退出码与实际用例数。按 `<工具契约文档位置>` 区分内容违规和无法判定；未知状态不放行，不将所有非零码或数字 2 一律归类。
- 报告三层结论和需求缺口。声称持续门禁生效时，另附真实 CI 运行、平台保护和结果消费证据；一次本地通过不足以支持该结论。
```

合入后用新会话和可控故障验证这些指令确实在修改前到达、结果被正确消费，见[接入验收](../references/integration.md)。详细操作留在技能参考中；常驻文件不需要复制整个工作流。
