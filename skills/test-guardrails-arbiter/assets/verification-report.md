# 三层检查报告

## 检查对象

- 任务与观察范围：
- 比较基线 base SHA / 候选 head SHA：
- 工作区内容标识（相关暂存、未暂存、未跟踪文件及哈希）：
- 策略 / baseline 版本：
- 工具版本与关键环境：
- 检查前后快照是否一致：
- 影响分析依据及未覆盖范围：

## 路径不变量

| 清单 ID / 风险 | 命中路径（含旧路径） | invariant / 已读背景 | 必需 checks |
|---|---|---|---|

## 原始证据

| 层 / 检查 | 命令、目录、范围 | 运行者 / 快照 | 原始退出码 | 用例数或扫描读数 | 原始产物位置 | 结论 |
|---|---|---|---|---|---|---|

- Tests：断言的可观察行为、回归反证结果；覆盖率工具、生产单元、原始 covered/total、既有阈值与排除项。未执行项说明原因。
- Guardrails：enforced 违规与 report-only 发现分别列出；baseline 单调性及哨兵读数。
- ARBITER：命中的新增行及规则；删除、重命名、多行改写等 matcher 未覆盖部分的补充证据。

## 结论与行动

- 总状态：`Passed` / `PolicyViolation` / `InfrastructureFailure`
- 已证实的违规（即使同时有基建问题也保留）：
- 缺失证据、无法判定项和确实不适用项及理由：
- 修复位置 / 机制 owner：
- 最小复验命令集合：
- 重试记录与停止条件（如适用）：
- 当前快照能否支持交付结论：

总状态是对已记录证据的汇总，不是执行器产生的原始 verdict，也不是额外的发布授权。
